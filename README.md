# LogiQD · .github

Perfil público de la organización en [github.com/LogiQD](https://github.com/LogiQD).

- `profile/README.md`: la presentación que se ve en la página de la organización.
- `profile/assets/`: banners (claro y oscuro) y recursos de marca.
- `scripts/build_banner.py`: regenera los banners SVG con las imágenes incrustadas (`python3 scripts/build_banner.py`).
